# AutoSort Music

Утилита переименовывает музыкальные файлы по их тегам: `Исполнитель - Название.mp3`.
Если тегов нет — ищет трек в интернете (MusicBrainz, затем iTunes) и берёт название оттуда.
Если найти не удалось — файл не трогает и сообщает об этом.

## Скачать готовую сборку

Не хотите возиться с git — скачайте [готовый ZIP со страницы релизов](https://github.com/Donya-12/dm-autosort/releases/latest), распакуйте в любую папку и запустите `Запустить.bat`.
Внутри уже лежат все файлы; нужен только Python 3.10+ (без него `.bat` подскажет, что установить).

## Что важно

- **По умолчанию ничего не меняется** — показывается только предпросмотр.
- Изменения применяются с флагом `--apply`.
- Каждое переименование пишется в журнал `_autosort_log.csv`, его можно **отменить** командой `--undo`.
- Существующие файлы не перезаписываются: при совпадении добавляется `(2)`, `(3)` и т. д.
- Вложенные папки обходятся рекурсивно.

## Установка

Нужен Python 3.10+ и библиотека `mutagen`:

```powershell
pip install -r requirements.txt
```

## Быстрый запуск без командной строки

Перетащите папку с музыкой на файл **`Запустить.bat`** (или запустите его и вставьте путь).
Скрипт покажет предпросмотр и спросит, применять ли изменения.

## Запуск из командной строки

```powershell
# предпросмотр — ничего не меняет
python autosort_music.py "D:\Music"

# применить переименование
python autosort_music.py "D:\Music" --apply

# отменить последний запуск
python autosort_music.py "D:\Music" --undo

# отменить конкретный запуск (RUN_ID виден в журнале)
python autosort_music.py "D:\Music" --undo 20261112-232701-232d
```

## Формат имени

По умолчанию: `{artist} - {title}` → `Daft Punk - Get Lucky.mp3`.

Свой шаблон задаётся через `--format`. Доступные поля:

| Поле | Значение |
|---|---|
| `{artist}` | исполнитель |
| `{title}` | название трека |
| `{album}` | альбом |
| `{albumartist}` | исполнитель альбома |
| `{year}` | год |
| `{track}` | номер трека (две цифры, если есть) |

Примеры:

```powershell
python autosort_music.py "D:\Music" --format "{track}. {artist} - {title}"
python autosort_music.py "D:\Music" --format "{artist} - {album} - {track} {title}"
```

Пустые поля аккуратно убираются (не будет `[]` или ` -  - `).

## Как работает поиск в интернете

1. Сначала читаются теги файла (ID3, Vorbis, MP4/FLAC и т. д.).
2. Если не хватает названия или исполнителя — имя файла очищается от мусора
   (`01_`, `[Official Video]`, `320 kbps`, ссылки и т. п.) и используется как запрос.
3. Запрос уходит в **MusicBrainz**, при неудаче — в **iTunes Search API**.
4. Результат принимается, только если совпадение достаточно точное **и длительность
   трека совпадает с файлом** (±10 секунд). Это защищает от чужих версий и каверов.
5. Найденный результат кэшируется, чтобы повторный запуск не дёргал сеть.

Нужен интернет. MusicBrainz ограничивает частоту запросов, поэтому обработка
большой папки без тегов занимает время (примерно 1–2 секунды на файл).

## Полезные флаги

| Флаг | Что делает |
|---|---|
| `--apply` | действительно переименовать |
| `--format "..."` | шаблон имени |
| `--no-online` | не искать в интернете, использовать только теги |
| `--min-score N` | минимальное совпадение онлайн-поиска (по умолчанию 85) |
| `--tolerance N` | допустимая разница длительности в секундах (по умолчанию 10) |
| `--no-recursive` | не заходить во вложенные папки |
| `--undo [RUN_ID]` | отменить переименования |

## Поддерживаемые форматы

MP3, FLAC, M4A/MP4/M4B, OGG/Opus, WAV, WMA, AIFF, APE, WV, DSF.

## Откат и журнал

Журнал `_autosort_log.csv` создаётся в корне обработанной папки. В нём хранятся
старое и новое имя, источник названия (теги/онлайн), оценка совпадения и ошибки.
`--undo` читает журнал и возвращает имена в обратном порядке. Файлы с изменёнными
вручную именами откат не затрагивает — только записи текущего журнала.

## Ограничения

- Утилита только **переименовывает** файлы, теги не изменяет.
- Для файлов без тегов нужен интернет; в офлайне используйте `--no-online` —
  такие файлы будут пропущены.
- Онлайн-базы не всеведущи: редкие, локальные и самодельные треки могут не найтись.
- iTunes API может быть недоступен в некоторых сетях — тогда остаётся MusicBrainz.
- Слишком длинные имена обрезаются с учётом ограничения Windows на длину пути.
